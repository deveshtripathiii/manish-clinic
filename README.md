# Dr. Manish Dental Clinic Website

A modern, mobile-friendly Dental Clinic website with 30-minute OPD slot booking via WhatsApp and an interactive **Manish AI** dental assistant.

## 🚀 Features
- **30-Minute OPD Slot Booking**: Single slot selection per patient across morning and evening sessions.
- **WhatsApp Integration**: OPD booking is instantly sent to **9956533534** with complete patient summary.
- **Patient Code**: Automatically generated as the **first four digits** of the patient's phone number.
- **Doctor Profile**: Uses Dr. Manish's official photo in hero, about, and AI assistant avatar.
- **Manish AI Assistant**: Interactive AI assistant offering instant dental advice, OPD slot booking guidance, clinic timings, and FAQs in Hindi & English.
- **100% Mobile Friendly**: Responsive layout with a sticky bottom action bar for instant call, booking, and AI access.

## 📂 File Structure
- `index.html` - Main website structure & forms
- `style.css` - Responsive styles & modern dental healthcare theme
- `app.js` - Booking logic, slot management, WhatsApp generator & Manish AI
- `assets/doctor.jpg` - Doctor's photo

## 🌐 How to Open
Double-click `index.html` in the `dental_clinic` folder on your Desktop, or run:
```bash
open ~/Desktop/dental_clinic/index.html
```
